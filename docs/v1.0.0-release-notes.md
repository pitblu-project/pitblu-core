# pitblu-core v1.0.0

This release adds guided installation/configuration tools and an observational
thermometer communication heartbeat to REST, SSE and MQTT. It includes the
reconnection improvements made during development. Existing installations
can use the [guided upgrade](https://github.com/pitblu-project/pitblu-core/blob/main/docs/installation.md).
Keep a protected backup and avoid upgrading during an active cook.

Before publication, the operator verified four inserted probes against the
iGrill display, explicit Disconnect/Connect, force reconnect, automatic recovery, MQTT/SSE and
a twelve-hour physical soak without recorded anomalies. Details and exact counts
are in the [Pi test record](https://github.com/pitblu-project/pitblu-core/blob/main/docs/physical-evidence.md).

**Acceptance limitation:** The owner directed publication while some final
physical gates remain unverified. In particular, connected-but-unresponsive
heartbeat ageing was not demonstrated, and the stable tag has not itself been
smoke-tested on the Pi. This is a release-owner waiver, not a pass. See the
[release status](https://github.com/pitblu-project/pitblu-core/blob/main/docs/release-status.md)
and [checklist](https://github.com/pitblu-project/pitblu-core/blob/main/docs/physical-acceptance.md).

Continue independent temperature checks; pitblu-core has no cooking alarms or
food-safety decisions. Keep administrator and MQTT credentials private.
