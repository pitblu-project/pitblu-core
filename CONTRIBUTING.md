# Contributing

Use Python 3.11 through 3.13 and British English in user-facing text. Keep code,
tests, documentation and provenance aligned. Run the checks in the
[development guide](docs/development.md) before submitting changes.

Follow the [documentation policy](docs/README.md). Keep the core API and
[integration contract](docs/frontend-integration.md) current when public behaviour
changes. Never commit credentials, Bluetooth addresses, private network details,
databases, backups or generated dependency inventories.
